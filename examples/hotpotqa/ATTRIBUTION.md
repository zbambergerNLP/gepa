# Attribution

- **Dataset:** HotpotQA, Yang et al. (2018), https://hotpotqa.github.io/ and HuggingFace `hotpot_qa/fullwiki`. The production loader follows `gepa-ai/gepa-artifact`'s `HotpotQABench`, which calls `load_dataset("hotpot_qa", "fullwiki")`. Bundled `context` passages are deliberately discarded; only question, answer, identifiers, and supporting titles are retained.
- **Program:** `gepa-ai/gepa-artifact`, `gepa_artifact/benchmarks/hotpotQA/hotpot_program.py`. The harness preserves its four optimized components (`summarize1`, `create_query_hop2`, `summarize2`, `final_answer`), two retrieval hops, and `k=7` per hop. The artifact's hosted ColBERT/BM25 retrieval is replaced with the public MediaWiki search/extract API as required for this standalone harness.
- **Metric:** HotpotQA's normalized exact match is the optimization score, as in the artifact's `dspy.evaluate.answer_exact_match`. `normalize_answer`, `em_score`, and token `f1_score` follow the official HotpotQA evaluation semantics; F1 is diagnostic feedback rather than the primary objective.
- **Wikipedia content:** Retrieved from English Wikipedia through MediaWiki and subject to Wikipedia's CC BY-SA licensing and API terms. The client sends an identifying user agent and persistently caches query results.
- **Smoke sample:** `data/hotpotqa_distractor_sample.jsonl` is a committed 20-record data-only smoke input. Its supplied passages are not consumed. It is used only when explicitly passed with `--data-path`.
