# Attribution

- **Dataset:** Jiang et al. (2020), “HoVer: A Dataset for Many-Hop Fact Extraction and Claim Verification,” https://arxiv.org/abs/2009.07258 and https://github.com/hover-nlp/hover. The loader downloads the official `data/hover/hover_train_release_v1.1.json`, parses titles from `supporting_facts`, and keeps examples with exactly three unique documents, matching `gepa-ai/gepa-artifact`'s `hoverBench` filter.
- **Program:** `gepa-ai/gepa-artifact`, `gepa_artifact/benchmarks/hover/hover_program.py`. The harness preserves its three retrieval hops, retrieval counts 7/7/10, and four optimized components (`summarize1`, `create_query_hop2`, `summarize2`, `create_query_hop3`). The artifact's local 2017-Wikipedia BM25 index is replaced with the public MediaWiki search/extract API for this standalone harness.
- **Metric:** The primary score is discrete complete retrieval: all three normalized gold titles must occur among the pages actually returned by the retriever. This follows the artifact's `discrete_retrieval_eval`. Gold-document recall is also reported as a diagnostic.
- **Wikipedia content:** Retrieved from English Wikipedia through MediaWiki and subject to Wikipedia's CC BY-SA licensing and API terms. The shared client uses an identifying user agent and a persistent SQLite query cache.
- **Smoke data:** The three-record synthetic smoke set is selected only with `--smoke`; production load failures never trigger it implicitly.
